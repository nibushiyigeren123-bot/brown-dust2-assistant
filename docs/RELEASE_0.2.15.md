# 0.2.15 预览版：活动战斗与遇错继续

本版继续完善日常作战台，加入活动战斗执行链，并修复单项失败后整轮中断的问题。默认仍为只读模式，资源消费模块需按实际情况配置后启用。

## 本版更新

- 单段和队列执行前先由辅助自行导航，连续确认主菜单后再核对日期、缓存与任务。补充已知页面的返回识别和有界等待，未知页面不盲点。
- 活动支持普通／挑战、连续／快速战斗设置，共享每日 AP 预算；提交前保存原操作和点击回执，结果未确认时不重发、不清空未决。只用免费或设置允许的已持有额外 AP，不购买、不改阵容。
- 单项异常、无结果或损坏回执保留失败记录，继续后续独立勾选项；不自动重试本轮失败项。活动未决仅对已核实不依赖共享 AP 的独立项目放行，其他未决仍按现有保护处理。
- 全部勾选项处理后，在“执行过程”窗口汇总成功、失败、受阻、跳过和未运行数量，并列出错误、未决与运行记录入口。有错显示“执行结束，有错误”，不当作全部任务成功。
- 新增“继续未运行项”：配置改变后，从旧中断队列建立带来源校验的新队列，只处理未运行项，不改旧配置哈希，不重放原失败或已完成消费。
- 保留停止／F8、模块边界暂停、换日、配置变化和执行锁保护；修复模块捕获异常后丢失停止信号的问题。
- 完善每日／每周领奖恢复、结果回收和 Windows 回执写入；装备继续按 R 优先、N 后备、单件分解和当日完成账本处理。

## 验证范围与待验证项

本次遇错继续的 15 项离线检查和原有 7 项队列策略检查通过，覆盖多项失败、损坏／缺失回执、未决保留、共享 AP 阻断、停止与恢复，以及错误汇总读取。冻结包完成模板、配置与规则自检；源码和便携包均检查打包完整性及私人数据排除。

日常领取与消费主要只能按游戏日实际验证，不能为测试重复领取或重放消费。本版保持预览状态：新错误继续策略下的完整实机日常循环、错误后的独立收尾及实际过程窗口显示，仍待后续游戏日逐步验证。活动挑战连续战斗的失败结果尚有待核对情况，不能把计划次数当作已完成次数。

N 品质卡片的实机字形、更多分辨率与游戏更新后的适配尚未全面验收；缺乏可靠样本时会停步留证。场景截图去重／首次校准方案尚未接入本版，不宣称已支持所有分辨率或停止重复留图。Boss 和邮箱保持手动，角色通行证保留入口。

## 下载与升级

- 首次使用：解压整个 Portable 包，运行 BD2Assistant.exe，先在默认只读模式下核对识别与设置。不能只复制 EXE。
- 升级已有安装：先关闭助手并备份原目录；更新程序时保留原 config、runtime、evidence，不用包内默认配置覆盖它们，也不要同时运行两份安装。
- 存在未决时先核对原回执，不通过清空账本或重发消费来恢复。配置改变的中断队列可用“继续未运行项”，失败项仍需单独核对。
- Source 包包含可编辑源码、模板、资源及公开验证脚本；不含个人配置、进度、完整实测截图或账号资料。

项目是持续迭代的非官方 Windows 本地视觉辅助。原创代码采用 MIT；游戏识别素材与第三方依赖见 NOTICE.md。
