# 0.2.15 · 2026-10-22 热修预览版

本版汇总 10 月 21—22 日修复：减少识别过程中的重复落盘，加入共用参考库和队列目标导航，并修复经营入口与历史账本清理。程序内部版本仍为 0.2.15，热修标识为 queue_templates_memory_20261022。保留预览状态；用户当前无法安排实机测试，本次不额外运行游戏日常或消费。

## 更新内容

- 内嵌 OCR 与画面参考匹配模型，使用 CPU，在助手任务进程内按需加载。无需独立模型服务或 GPU 后台；助手退出沿用 Windows Job 回收任务进程。
- 全流程共用 55 张 1280×720 页面参考图。头像、昵称和战力所在区域 (0,0,360,80) 统一置黑，整帧模型输入使用相同排除范围；保留其下方功能图标。
- 普通帧、裁片与 OCR 主要放入有界内存缓存。帧缓存默认 96 MiB，OCR 最多 64 项；报告保留近期观察与动作，关键状态、异常与最终结果落盘。96 MiB 仅为帧缓存预算，不是整个助手的内存硬上限。
- 提交和消费结果的关键图像在账本引用前持久化，保持原 path+sha256 回执兼容，支持内存释放或重启后的核对；已完成消费仍不能重复提交。
- 宿主按当前队列项指定主菜单目标，结合参考匹配与独立验证的关闭／返回控件纠正导航，确认到达主页便推进。未知页面无有效控件时等待或停止；模型不是任意指令和坐标规划的视觉代理。
- 经营入口使用固定轮换槽位；主页确认后有界重试打开，奖励领取不重发。任务和通行证减少冗余扫描，装备减少逐件详情与重复 OCR。
- 重复只读检查复用独立 inspection 目录，不覆盖真实队列运行指针。历史完成、已发、消费和分阶段任务账本保留，继续清理可丢弃的旧空缓存。
- 保留停止／F8、鼠标移动、窗口几何、前景、换日、原停止队列、未决与消费保护。

## 验证范围

8 组共 385 项离线检查通过：新参考与内存识别 88、队列继续 16、队列策略 7、返回导航 38、经营 38、提速 142、模型接入 17、清理保留 39。
包括 3000 次观察零普通 PNG、真实 CPU 模型、WinRT 管线 OCR、装备选择／双确认／结果／返回整条图像链清空内存后重载核对，以及拒绝重复消费。最终冻结程序的自检和保存脱敏画面的只读 worker 检查通过。

上述是离线与打包验证。完整新版实机日常、实时导航与优化后耗时尚未验收；保存画面识别成功不代表游戏实测成功。新活动、皮肤和更多窗口状态仍需用户实际反馈。后续有具体问题再更新。

## 下载与升级

- 首次使用：解压整个 Portable 包，运行 BD2Assistant.exe。默认只读，先核对设置；不能只拿 EXE。
- 已有安装：先关闭助手并备份原目录，再更新程序文件。保留原 config、runtime、evidence，不用包内默认配置覆盖，不同时运行两份安装。
- 原停止队列和历史 pending 保留，不清账本、不把历史完成改成新一天、不通过重发消费恢复。用户自行安排后续实机 debug。
- Source 包含可编辑源码、模型、通用配置、识别素材及账号区域已遮黑的完整参考图；不含原始账号截图、个人配置、运行账本或本机交接记录。
