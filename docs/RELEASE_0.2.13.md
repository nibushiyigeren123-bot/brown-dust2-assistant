# 0.2.13 预览版

登录后可能回到上次停留的游戏场景。本版已实测从镜中酒馆识别右上房子返回，连续两帧确认主菜单，并完成启动时每日／每周可领奖励检查与任务进度核对；本次没有新增领奖、战斗或装备消费。

- 镜中赛季末判定合并进镜中之战。实际进入场景并点击自动战斗，确认赛季结算提示后显示“赛季末 · 已跳过”，返回主页继续其他段；不增加战斗完成次数。
- Boss已改为一次性挑战，由玩家手动完成；删除Boss预留按钮和默认配置占位。角色通行证仍预留。
- 北京时间每天08:00刷新游戏日，旧日完成记录不用于今天；清理保留本游戏日及前一日，并保护未决记录。
- 狩猎读取实际免费米饭／火炬余额，支持指定目标、库存最少圣石及按所选目标用完当前免费体力；每日固定1次与额外计划分开核对。
- 任务进度与页面识别分别显示。重复领奖模块改为“本日已检查 · 仍会复查”，不将“检查过”当作以后无需检查。
- 执行时自动打开过程窗口，支持滚动查看与停止；关闭查看窗口不等于停止。

首次启动默认只读，消费模块默认停用、额度为零，不购买体力、不更换阵容、不处理邮箱，不获取账号身份。实机执行“进入主菜单”会顺查并领取当前可领的每日／每周奖励；只读模式不会点击游戏。

验证范围：本地候选与安装各44项界面检查和13项日志检查、31项镜中合并边界、38项进度／缓存边界通过；12段只读队列全部inspected且无游戏点击。保存的真实结算帧只读识别通过。实机导航范围如上，不等同于重新完成所有日常。新日期装备通用链已接入，但本次没有新实机消费验收；活动普通／快速战斗通用提交仍待接入。

升级请完整保留旧文件夹作为回退，将新版解压到新目录。需要延续同一游戏环境的配置与进度时，在助手和游戏操作都停止后，复制自己的config与runtime；不要套用别人的进度缓存。不同使用环境请分目录保存，因为程序不读取账号来自动区分。
