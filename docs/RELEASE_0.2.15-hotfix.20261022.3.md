# 0.2.15 · 10月22日第三次热修预览：领奖 pending 与独立模块隔离

修复一份未结清的每日/每周领奖记录阻塞经营、公会、狩猎等独立模块的问题。程序内部仍为 0.2.15，热修标识 pending_claim_isolation_20261022。

## 修复行为

- 仅当记录位于规范任务领奖账本、日期为当前游戏日、schema 为整数 1、领取类型与页面/坐标/证据完整符合现有每日或每周领取协议时，保留该 pending 并允许独立模块继续。
- 经营、免费抽取、公会、狩猎、女神像、镜中之战、装备、活动和通行证保留各自的账本、消费、资源、窗口、主菜单和停止检查；不会因任务领奖的 pending 一律受阻。
- 不删除或改写原 pending，不把旧账本迁移成今日完成，不自动恢复或重跑队列。显式任务领奖入口仍按原恢复流程核对自己的记录；同族外部记录、未知/损坏/缺证据记录、错误路径及同日双账本仍阻断。
- 继续保留已有奖励弹窗图片识别、只回主菜单的导航范围、内存缓存及奖励弹窗 SendInput 路径；没有更换小模型或新增服务。
