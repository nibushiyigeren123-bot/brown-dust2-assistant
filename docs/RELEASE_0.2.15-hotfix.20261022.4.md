# 0.2.15 · 图片识别训练与公会入口修复

本次修复主页公会入口变成“公会联合战 D-6”后旧图标模板失效的问题，并补充按12项队列组织的页面识别训练。

- 旧入口识别、原账本、历史pending、停止队列、已完成消费保护保持。模型在助手工作进程内按需CPU加载，退出释放，无模型服务。
