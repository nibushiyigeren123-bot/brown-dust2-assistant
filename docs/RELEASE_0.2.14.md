# 0.2.14 修复版

修复0.2.13发布包的导航配置缺字段和公会签到无法启用问题。

- 发布脱敏只移除明确的来源字段，保留图像识别所需的 source_client_width、source_box 和 source_panel_size。自检实际执行导航校准分支，缺失校准时给出可读错误。
- 日常设置新增“公会签到”页，可启用或停用。加入队列与模块启用分别显示；停用时点击实机执行会直接打开对应设置页。队列在开始前检查公会配置，避免做到一半才因开关关闭而退出。
- 公会停用也会保存中文停止回执。队列子进程异常或缺回执时不再残留“正在运行”。
- 已在用户下载的0.2.13中单独启用公会并实测：进入、签到奖励提示、关闭提示、返回主页全部完成；当天记录无未决。此后未重复签到、经营或免费抽取。实机执行链原本已存在，本版补齐公开分发中的设置和反馈。

验证：原工程与公开源码各15项公会设置、预检、回执、重复进入保护检查；13项脱敏校准回归、7项队列边界检查。最终ZIP解压后的自检、界面与只读验证另见发布验证回执，不能将模拟检查当作全日常实机验收。

活动战斗按用户最新要求暂不处理。正常／快速战斗的通用执行链仍未接入，不会因本次公会修复自动启用；历史5次战斗及快速战斗演示不等于公开UI已能连续执行。本版不宣称整套日常已全部实机通过。

北京时间08:00刷新游戏日；不读取游戏账号，不购买资源，不修改阵容，邮箱手动。角色通行证保留入口，Boss由用户手动。

升级建议解压到新目录，关闭旧助手及执行任务后复制自己的config和runtime以保留设置与进度。首次使用默认只读，公会开关位于“日常设置 → 公会签到”。0.2.13旧资产保留供追溯，不覆盖。
