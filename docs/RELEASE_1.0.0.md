# 1.0.0 正式版

2026-10-24。本版将最新 r8d 导航恢复版本作为 1.0.0 正式版发布，程序窗口标题、构建信息及文档统一为 1.0.0。

## 本版变化

- 女神广场按修复后的五秒等待流程处理，保留历史未决记录，不为恢复而重发未证实动作。
- 主页活动“解锁”入口独立识别，与活动中心普通／挑战入口区分；确认主页后按当前队列目标导航。
- 通行证按启用设置逐本点击右侧记事板及底部“全部获得”；等级奖励保留配置开关。组内复用入口定位，减少重复 OCR。
- 通行证不读取任务完成度、不滚动、不核对奖励到账；回执记录动作完成与奖励未核实。旧未决和未知输入保持停步，不自动补点。
- 延续 CPU 内嵌 OCR、脱敏参考匹配、F8／停止、鼠标移动、前景窗口、日期与消费保护。Boss及邮箱仍由用户手动。

## 验证范围

此前定向实机记录覆盖 r6 女神广场五秒流程、r7 主页活动解锁入口，以及最终 r8d 三本通行证的任务／等级共六组动作、返回主菜单与 worker 退出。通行证动作完成不等于奖励到账已核实。

此次 1.0.0 重新构建并检查公开包的模块注册、配置、模板和 CPU 向量缓存；保存画面检查属于只读识别验证。正式版是本次发布标签，不代表重新完整实测全部十一项队列。

完整旧队列未重跑；已完成的活动五场和镜中四十免费资源不能为发布重放。原停止队列、消费记录及未决动作不清除、不重发。本次打包没有向游戏发送输入。

## 下载与升级

- 首次使用：完整解压 Portable 包，运行 BD2Assistant/BD2Assistant.exe，先核对模块设置。程序启动不会自动开始队列，点击执行后才运行。不能只提取 EXE。
- 已有安装：先关闭助手并备份旧安装，保留个人 config、runtime 和 evidence；只更新程序及随附资源，不用通用默认配置覆盖个人设置，不同时运行两份安装。
- Source 包含源码、通用配置模板、脱敏参考图和模型，可独立构建；不包含账号资料、私人配置、运行账本、完整测试证据、日志、缓存目录或本机维护档案。assets/step_vision/cache.json 是随版本分发的公开参考向量库，不是个人运行缓存。
