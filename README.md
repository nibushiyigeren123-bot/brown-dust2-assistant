# 棕色尘埃2 日常作战台

0.2.15 开源预览版 · Windows 本地视觉辅助 · MIT 代码许可

[下载便携程序与源码](https://github.com/nibushiyigeren123-bot/brown-dust2-assistant/releases/tag/v0.2.15)

Windows 本地视觉辅助工具。读取游戏画面、日期和本地进度缓存，不获取游戏账号、账号ID、密码或登录凭据。源码包不包含个人配置、runtime、完整实测截图、历史交接及本机维护脚本。

Python 3.14，安装 requirements.txt 后执行 `python -X utf8 tools/assistant_app.py`。首次启动从 templates/config 生成本地配置，默认只读，资源消费模块默认停用；使用 Windows 系统 OCR，需安装对应的中英文识别语言。构建便携程序：安装 build-requirements.txt 后执行 `python -X utf8 tools/build_desktop.py`。

缓存按游戏日与模块分别存储在 runtime。游戏日按北京时间每天早上08:00刷新，凌晨零点不换日；启动、空闲和执行前同步日常与活动日期。新一天不继承旧日完成标记，未决操作阻止换日，跨刷新点执行会停步保留回执。旧缓存保留今天与昨天，并保护当前使用日期和未决记录。每份安装独立保存缓存，不获取或自动切换游戏账号。

任务进度与本轮识别状态分别显示。仅识别到页面不会标记任务完成；有明确未完成证据时显示未完成，缺少依据或存在未决操作时显示待核对。可重复领奖项目注明上次检查，不据此跳过新检查。默认自动清理旧缓存，保留今天和昨天，并保护当前选用日期及未决记录；也可手动清理或关闭自动清理。配置、日志、截图及恢复备份不在清理范围内。

只读模式不发送游戏输入。实机执行“进入主菜单”时会顺查并领取当前可领的每日／每周奖励，再核对任务进度；不会因此开战。点击单段或队列命令会自动弹出过程窗口，显示识别、判断、等待、回执与异常。可以关闭自动滚动回看，也可以跳到最新；关闭过程窗口不停止任务。

单段与队列都先连续确认主菜单，再核对日期、缓存和待执行命令；中途恢复不重放已完成模块。活动战斗支持普通／挑战、连续／快速设置，两种难度共享 AP 预算和当日消费账本。实际余额从游戏读取；关闭“仅免费”只允许使用已持有的额外 AP，不购买。设置预演、模拟与实际消费的验收范围分别记录在发布说明中。

每日／每周领奖掉线后保留原动作，核对当前任务页，仅领取当前仍可领取的奖励；确认奖励回执与领取后状态再结清未决。消费类未决不会沿用这条恢复逻辑。装备单选 R 优先，无合格 R 再选 N；已完成动作由当日账本保护。镜中之战进入场景并点击自动战斗后判定赛季结算，显示“赛季末 · 已跳过”，不增加战斗完成次数。Boss由用户手动，角色通行证保留入口。未知页面停步留证，不反复点击。

`--self-check <目录>` 在公开包中只验证模板加载、配置与规则，不代表实机战斗或领奖验收。项目原创代码采用 [MIT License](LICENSE)。游戏素材及第三方依赖的权利单独见 [NOTICE.md](NOTICE.md)。

本版更新、升级方法与验收边界见 [0.2.15 发布说明](docs/RELEASE_0.2.15.md)。单项错误后继续独立项，最终在执行过程窗口汇总；实机日常按游戏日逐步验证。
