# 棕色尘埃2 日常作战台

0.2.4 预览版 · Windows 本地视觉辅助 · MIT 代码许可

[下载便携程序与源码](https://github.com/nibushiyigeren123-bot/brown-dust2-assistant/releases/tag/v0.2.4) · [模拟验证范围](docs/VALIDATION.md)

Windows 本地视觉辅助工具。读取游戏画面、日期和本地进度缓存，不获取游戏账号、账号ID、密码或登录凭据。源码包不包含个人配置、runtime、完整实测截图、历史交接及本机维护脚本。

Python 3.14，安装 requirements.txt 后执行 `python -X utf8 tools/assistant_app.py`。首次启动从 templates/config 生成本地配置，默认只读，资源消费模块默认停用；使用 Windows 系统 OCR，需安装对应的中英文识别语言。构建便携程序：安装 build-requirements.txt 后执行 `python -X utf8 tools/build_desktop.py`。

缓存按日期与模块分别存储在 runtime；新安装默认按本地日期建立缓存。本地已保存的日期会保留，不会因电脑跨日而清空进度。设置中更换数据缓存日期会同步日常与活动配置；任何未决操作必须先核对，不能靠换日期重放。每份安装独立保存缓存，不自动识别或切换游戏账号。

任务进度与本轮识别状态分别显示。仅识别到页面不会标记任务完成；有明确未完成证据时显示未完成，缺少依据或存在未决操作时显示待核对。可重复领奖项目注明上次检查，不据此跳过新检查。默认自动清理旧缓存，保留今天和昨天，并保护当前选用日期及未决记录；也可手动清理或关闭自动清理。配置、日志、截图及恢复备份不在清理范围内。

点击单段或队列命令会自动弹出过程窗口，显示识别、判断、等待、回执与异常。可以关闭自动滚动回看，也可以跳到最新；关闭过程窗口不停止任务。

已有模块按注册表串行执行。新周期通用装备链、活动正常/快速战斗通用提交仍待接入；Boss战、镜中赛季结算、按天角色通行证仅保留停用入口。游戏更新后识别可能需要重新适配，未知页面会停步核对。

`--self-check <目录>` 在公开包中只验证模板加载、配置与规则，不代表实机战斗或领奖验收。项目原创代码采用 [MIT License](LICENSE)。游戏界面局部识别模板及第三方依赖的权利与许可单独见 [NOTICE.md](NOTICE.md)。

解压便携程序后运行 `BD2Assistant.exe`。首次启动为只读模式，先核对窗口识别及设置，再按各模块支持范围使用。请将整个 BD2Assistant 文件夹一起保留，不能只复制 EXE。
